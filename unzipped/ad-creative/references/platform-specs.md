# Platform Ad Specs — Complete Reference

Read this file when producing ad creatives to ensure every asset meets platform requirements.

---

## Meta (Facebook / Instagram)

### Image Ads
| Format | Dimensions | Aspect Ratio | Max File Size |
|--------|-----------|--------------|---------------|
| Feed (Square) | 1080 × 1080 | 1:1 | 30 MB |
| Feed (Landscape) | 1920 × 1080 | 16:9 | 30 MB |
| Feed (Portrait) | 1080 × 1350 | 4:5 | 30 MB |
| Stories / Reels | 1080 × 1920 | 9:16 | 30 MB |
| File types: JPG, PNG | | | |

### Video Ads
| Format | Dimensions | Aspect Ratio | Duration | Max File Size |
|--------|-----------|--------------|----------|---------------|
| Feed (Square) | 1080 × 1080 | 1:1 | 1s – 241min | 4 GB |
| Feed (Portrait) | 1080 × 1350 | 4:5 | 1s – 241min | 4 GB |
| Stories / Reels | 1080 × 1920 | 9:16 | Up to 60s | 4 GB |
| File types: MP4, MOV | | | | |

### Carousel Ads (2–10 cards)
| Format | Dimensions | Aspect Ratio |
|--------|-----------|--------------|
| Card (Image) | 1080 × 1080 | 1:1 |
| Card (Video) | 1080 × 1080 | 1:1 |

### Copy Limits
| Field | Character Limit | Notes |
|-------|----------------|-------|
| Primary Text | 125 | Truncated after ~3 lines on mobile |
| Headline | 27 | Displayed below image |
| Description | 27 | May not show on all placements |
| Carousel Card Headline | 32 | |
| Carousel Card Description | 18 | |

### Rejection Triggers
- Image text >20% of image area (soft guideline, still impacts delivery)
- ALL CAPS in ad copy
- Before/after images implying unrealistic results
- Personal attributes ("Are you overweight?")
- Excessive punctuation (!!!, ???)
- Misleading claims or clickbait

## TikTok

### Video Ads (5–60s, recommended 9–15s)
| Format | Dimensions | Aspect Ratio |
|--------|-----------|--------------|
| Vertical (primary) | 1080 × 1920 | 9:16 |
| Square | 1080 × 1080 | 1:1 |
| Landscape | 1920 × 1080 | 16:9 |
| File types: MP4, MOV | Max: 500 MB | |

### Copy Limits
| Field | Limit |
|-------|-------|
| Ad description/caption | 100 chars |
| Display name | 40 chars |

### Best Practices
- Hook in first 1–3 seconds (critical — users scroll fast)
- Native/UGC style outperforms polished brand content
- Use trending audio styles (but not copyrighted music)
- Vertical (9:16) gets significantly better delivery than square or landscape
- Text overlays must be within safe zones (not cut off by UI elements)

## Quick Reference: Aspect Ratios → Tool Parameters

When using `image_generate` or `video_generate`, map platform formats to tool aspect ratios:

| Platform Need | Closest Tool Aspect Ratio |
|--------------|--------------------------|
| 1:1 (feed square) | `1:1` |
| 4:5 (Meta portrait feed) | `4:5` |
| 9:16 (stories, reels, TikTok, Shorts) | `9:16` |
| 16:9 (landscape, YouTube) | `16:9` |
| 1.91:1 (Google Display, Twitter rectangle) | `16:9` (crop if needed) |
| 4:3 (YouTube classic) | `4:3` |
| LinkedIn horizontal 1200×628 | `16:9` |
| LinkedIn square 1200×1200 | `1:1` |
